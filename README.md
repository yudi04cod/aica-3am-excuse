One excuse a hardware wallet gives for refusing to sign a transaction
at 3 AM — its seed phrase is asleep, dreaming in private keys, and it
doesn't wake up for impulse buys.

`main.py` (Python 3, standard library only, deterministic) writes that
single line (151 characters) to `/output/entry.txt`.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
